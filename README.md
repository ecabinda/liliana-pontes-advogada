# Liliana Pontes - Advogada | Website Institucional

Landing page profissional e moderna desenvolvida em **Next.js 14**, **Tailwind CSS** e componentes interativos com micro-animações, concebida para o escritório de advocacia da **Dra. Liliana Pontes** em Lisboa (Parque das Nações).

---

## 🏛️ Sobre o Projeto

O design reflete elegância, rigor e sobriedade institucional, combinando tons de espresso profundo, taupe nobre e apontamentos dourados discretos, integrando a identidade e instalações reais do escritório.

### 🌟 Destaques e Funcionalidades

- **Cabeçalho & Navegação:** Monograma oficial **LP**, menu com navegação fluida, botão de chamada direta (`918 651 224`) e CTA *"Marcar Consulta"*.
- **Hero Section:** Conceito institucional com recorte arquitetónico curvo (*curved-bottom-hero*), badge de localização em Lisboa (Parque das Nações) e cartão executivo com a fotografia real da sala de conferências e reuniões.
- **Rede Internacional Marquee:** Ticker infinito com os polos de Lisboa (Sede), Póvoa de Varzim, Paris (França), Hamburgo (Alemanha) e São Paulo (Brasil).
- **Experiência Jurídica & Balança da Justiça:** Elemento estilizado com física de contrapeso suave, selo de acompanhamento 24/7 e métricas (4.7★ Google, +15 Anos, 98% Satisfação, 5 Polos).
- **Áreas de Atuação:** 9 especialidades jurídicas completas com filtros interativos por perfil e pré-seleção no formulário.
- **O Escritório (Showcase):** Galeria interativa com as fotografias reais do espaço executivo em Lisboa e detalhes de localização.
- **Testemunhos Reais do Google Maps:** Avaliação 4.7 estrelas com citações verificadas de clientes.
- **Contactos & Marcações:** Formulário com validação, integração direta com WhatsApp e mapa do Parque das Nações.
- **Botão Flutuante de WhatsApp:** Acesso rápido no canto inferior direito com anel de pulso contínuo.

## 💻 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/ecabinda/liliana-pontes-advogada.git
cd liliana-pontes-advogada
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
